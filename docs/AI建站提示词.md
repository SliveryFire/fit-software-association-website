## 一、主提示词（完整版）

### 角色

你是一位有 8 年经验的高级前端工程师兼 UI/UX 设计师，擅长为高校学生组织打造「现代、专业、有科技感」的品牌官网。你将独立完成**福州理工学院软件协会官方网站**的设计与前端开发，直接输出可运行、可部署的生产级代码。

### 项目背景

- **主体**：福州理工学院 软件协会（校级学生社团，业务指导单位为校团委 / 计算机相关学院）
- **目标受众**：在校学生（重点是大一新生）、协会现任成员、指导老师、校方领导、合作企业与兄弟社团
- **核心目标**
  1. 让一个从没听说过协会的新生，在 **30 秒内**看懂「协会是做什么的、能给我什么、怎么加入」；
  2. 用活动、项目、成果建立专业可信的形象；
  3. 给老成员提供资源入口（学习路线、课件、题库）；
  4. 为招新和对外合作提供统一的官方门面。
- **语言**：简体中文为主，Logo 与关键标题可配英文副标题（如 `Software Association · FIT`）
- **网站性质**：首版为**静态展示型官网**，无登录、无后台，但数据结构要预留后续接入 CMS 的能力
- **语气**：专业、克制、有活力；不要浮夸营销腔，不要「全国领先」这类空话

### 技术栈（严格遵守，不得替换）

- 构建：**Vite + React 18 + TypeScript**（严格模式，禁用 `any`）
- 样式：**Tailwind CSS v3** + CSS 变量实现设计令牌，禁止行内样式的硬编码颜色
- 组件：自行实现 shadcn/ui 风格组件，**不引入** Ant Design / Element / MUI / Bootstrap / jQuery
- 图标：`lucide-react`
- 动效：`framer-motion`（轻量使用，必须尊重 `prefers-reduced-motion`）
- 路由：`react-router-dom` v6
- 内容数据：全部放在 `src/content/*.ts` 或 `*.json`，**严禁把文案硬编码在组件 JSX 里**
- 包管理：`pnpm`；Node ≥ 18
- 部署：纯静态产物，需同时支持部署到 Vercel 与校内 Nginx 子目录（`base` 可配置）

> 若必须用 Vue：把上面框架部分换成 `Vue 3 + TypeScript + Vite + Vue Router + Pinia(可不用)`，其余要求不变。

### 各页面内容与模块要求

#### 1. 首页 `/`

### 设计规范

**品牌调性**：深空蓝 + 电光青，暗色为主视觉，亮色模式完整支持。

**颜色令牌（CSS 变量，亮/暗两套）**

| 令牌 | 亮色 | 暗色 | 用途 |
|---|---|---|---|
| `--brand` | `#1D4ED8` | `#3B82F6` | 主色、链接、选中态 |
| `--brand-strong` | `#1E3A8A` | `#60A5FA` | 强调文字 |
| `--accent` | `#06B6D4` | `#22D3EE` | 渐变、图标、数据高亮 |
| `--cta` | `#F97316` | `#FB923C` | 仅用于「加入我们」等主按钮 |
| `--bg` | `#FFFFFF` | `#0A0E1A` | 页面底色 |
| `--bg-soft` | `#F6F8FC` | `#111827` | 分区背景 |
| `--surface` | `#FFFFFF` | `#151B2B` | 卡片 |
| `--text` | `#0F172A` | `#E5E7EB` | 正文 |
| `--text-muted` | `#64748B` | `#94A3B8` | 次要文字 |
| `--border` | `#E2E8F0` | `#243044` | 描边 |

所有文字与背景对比度 **≥ 4.5:1**（大字号 ≥ 3:1），CTA 橙色按钮上必须用深色文字或加深橙色，确保达标。

**字体**

- 中文正文：`system-ui, -apple-system, "PingFang SC", "HarmonyOS Sans SC", "Microsoft YaHei", "Noto Sans SC", sans-serif`
- 英文与数字：`Inter`（自托管 woff2，`font-display: swap`）
- 等宽代码：`"JetBrains Mono", ui-monospace, SFMono-Regular, Consolas, monospace`
- **不引入需要授权的中文字体文件**（体积大且版权风险）

**字号阶梯（rem）**：`0.75 / 0.875 / 1 / 1.125 / 1.25 / 1.5 / 2 / 2.5 / 3.5 / 4.5`
- 正文 16px、行高 1.75；标题行高 1.25；中文标题字间距 0，英文副标题 `0.02em` 且大写
- 移动端标题最大不超过 2rem，避免折行难看

**布局**
- 12 列栅格，容器最大宽 `1200px`，左右安全边距 24px（移动端 20px）
- 区块上下内边距：桌面 96px / 平板 72px / 手机 56px
- 圆角：按钮 `10px`、卡片 `16px`、大容器 `24px`、头像 `full`
- 阴影只用两级；暗色模式下用「描边 + 微光」代替重阴影

**动效**
- 时长 150–300ms，缓动 `cubic-bezier(0.16, 1, 0.3, 1)`
- 滚动进入视口淡入上移 12px，只触发一次，子元素 stagger 60ms
- hover：卡片 `translateY(-2px)` + 描边变亮；按钮轻微提亮
- `prefers-reduced-motion: reduce` 时**关闭所有位移与视差**，仅保留透明度变化

**背景质感（可选但加分）**
- Hero 用径向渐变光斑 + 1px 网格线（`background-image` 实现，不用图片）
- 全站禁止大面积纯色块堆叠，注意留白节奏

### 响应式断点

`sm 640 / md 768 / lg 1024 / xl 1280`。必须确保：375px 宽无横向滚动、导航可正常展开、表格在手机端转卡片、时间轴在手机端改为单列左侧对齐。

### 无障碍（硬性要求）

- 语义化标签：`header/nav/main/section/article/footer`，每页唯一 `h1`
- 全站键盘可达，`:focus-visible` 有清晰焦点环（≥ 2px、对比明显）

### SEO 与分享

- 每页独立 `title`（≤ 30 个汉字）与 `description`（80–120 字），格式：`页面名 | 福州理工学院软件协会`

- 全站 `lang="zh-CN"`，URL 用英文短横线

### 性能预算

- 首屏 JS（gzip）≤ 180KB；Total Blocking Time 尽量低
- LCP ≤ 2.5s（4G 模拟）；CLS ≤ 0.1
- 图片统一 WebP/AVIF，`loading="lazy"` + 显式宽高，首屏图 `fetchpriority="high"`
- 路由级代码分割（`React.lazy` + `Suspense`）
- 图标按需引入，禁止整包导入

### 兼容性

最近两个大版本的 Chrome / Edge / Safari / Firefox、iOS Safari 15+、Android Chrome，**必须兼容微信内置浏览器与 QQ 浏览器**：不使用实验性 CSS（`@container` 等需有降级）、不依赖 `100vh`（改用 `100dvh` 并给 fallback）。

## 二、分阶段提示词（推荐用法）

> 每段单独发，等上一段完成再发下一段。这样出错可控、返工最小。

**第 0 段 · 定方案**

```text
我要为福州理工学院软件协会做一个官网。你先别写代码，帮我出方案：
1) 站点地图（页面与导航关系）；
2) 首页的纯文字线框图，从上到下每个区块写清楚放什么内容；
3) 视觉方向：给 2 套配色方案（含 hex 色值）和字体建议，说明哪套更适合高校技术社团；
4) 需要提前准备哪些素材和文案。
受众是大一新生 + 校方 + 合作企业，目标是招新和树立专业形象。风格要现代、克制、有科技感，不要花哨。
```

## 四、常见坑（做完对照一遍）

1. **信息编造**：AI 会自动生成「成立于 2015 年，会员 300+」这类假数据。主提示词里已禁止，但仍要人工核对每个数字。
2. **移动端第一**：校园场景 80% 流量是手机（尤其微信里点开），一定先在 375px 下看，再放大屏。
3. **导航过多**：社团官网最容易堆成 10 个一级菜单。控制在 6 个以内。
4. **图片太重**：手机拍的合照动辄 5MB。上线前统一压到 200KB 内、转 WebP。
5. **子路由 404**：静态部署到 Nginx 需配 `try_files $uri $uri/ /index.html;`；GitHub Pages 需 hash 路由或 404.html 技巧。
6. **字体版权**：别用「汉仪」「方正」商用字体，系统字体栈最安全。
7. **表单没后端**：首版用问卷星/腾讯问卷外链，别让 AI 假装写一个发不出数据的表单。
8. **暗色模式只改背景**：卡片、描边、阴影、代码高亮都要一起改，否则一片死黑。
9. **动效过度**：社团官网不是作品集，滚动视差 + 满屏动画会拖慢加载，也容易晕。
10. **无维护方案**：交代清楚「改内容只动 `src/content/*.ts`」，并把这条写进 README 第一段。
